# STUN-Panel

利用 Cloudflare Workers 实现的 Lucky STUN 内网穿透动态端口自动跳转，带监控大屏。

## 使用教程

本教程仅适用于已搭建好端口穿透的用户。关于如何实现端口穿透，请参考其他教程，例如：  
[STUN内网穿透 | Lucky开发分享](https://www.lucky666.cn/docs/modules/stun/)

> 在部署或使用过程中遇到任何问题，都可以向 AI 求助。求助时，请附带完整的日志或对问题的详细描述。

### 第一步：部署 Cloudflare Worker

点击一键部署按钮：  
[![Deploy to Cloudflare Workers](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/i5114514kf/STUN-Panel)

操作步骤：  
1. 选择 KV 命名空间，点击 **新建**。  
2. 点击 **创建和部署**。

### 第二步：绑定自定义域名

由于 `workers.dev` 域名被墙，建议绑定自定义域名并进行 IP 优选。  
具体可参考二叉树树的教程：  
[试试 Cloudflare IP 优选！让 Cloudflare 在国内再也不是减速器！ - 《二叉树树》官方网站](https://2x.nz/posts/cf-fastip/)

### 第三步：配置 Lucky Webhook 上报

现在需要让 Lucky 客户端将节点信息推送到导航页。

1. 进入 Lucky 后台 → **内网穿透** → **STUN内网穿透** → **设置**。  
2. 启用 **全局 Stun Webhook**，并填写以下配置：

   - **接口地址**：  
     `https://你的域名/?key=123456&name=#{ruleName}&addr=#{ip}:#{port}`
   - **请求方法**：`GET`
   - **请求头**：留空
   - **重试次数**：可适当增加
   - **接口调用成功包含的字符串**：`Update Success`

> **注意**：`key` 必须与代码中第 8 行的校验码一致（默认为 `123456`），可根据需要自行修改。  
> 也可以不改代码，给 Worker 加一个名为 `AUTH_KEY` 的环境变量来覆盖它（设置 → 变量和机密）。

### 第四步：使用

- **访问导航页**：直接访问 `https://你的域名/` 即可看到所有上报的节点。  
- **快捷跳转**：访问 `https://你的域名/节点名称` 会直接重定向到该节点的实时 IP 地址。

## 面板功能

- **节点卡片**：显示节点名、实时地址、上次上报时间，以及每 5 秒探测一次的实时延迟（超时显示"超时"）。
- **自动折叠超时节点**：某个节点**连续 3 次**探测超时（约 15 秒）后，卡片自动折叠成一行，只留名字和状态，避免一堆死节点刷屏；节点恢复后自动展开。
  - 用导航页顶部的开关可以关掉这个行为，或点"全部展开"手动展开全部。
  - 折叠状态记在浏览器本地（localStorage），刷新页面后仍然保持。
  - 点击卡片右下角的 `⌄` / `⌃` 可以手动折叠或展开单个节点；手动展开会清零计数（再连续超时 3 次会重新折叠）。
- **手动删除节点卡片**：见下一节（需要管理员权限）。

## 管理员模式（手动删除节点）

在面板地址后带上校验码即可进入管理员模式，例如：`https://你的域名/?key=123456`

- 每张卡片右下角会多出一个 `×` 按钮，点击并确认后即删除该节点卡片。
- **删除后 Lucky 继续上报也不会复活**：地址数据照常写入（所以恢复时是最新地址），但面板渲染时会跳过它。
- 被删除的节点会列在页面底部的"已删除节点"里，点 **恢复** 就能让它回到面板，不需要重新配置 Lucky。
- 不带 `key` 访问时，页面里**不会**渲染删除按钮，也不会注入任何口令——普通访客只能看，不能删。

> 带 `key` 的地址等同于删除密码，别公开分享。

## 本地测试

仓库自带一套行为测试，用假 KV 直接调用 Worker 的 `fetch`，不碰网络：

```bash
node --test test/worker.test.mjs
```

覆盖：webhook 上报与鉴权、`/<名字>` 跳转（含中文名、URL 编码）、面板渲染与管理员视图、删除/恢复/墓碑防复活、HTML 转义、以及自动折叠逻辑是否存在于页面脚本中。
